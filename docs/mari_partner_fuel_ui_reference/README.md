# Mari Partner Fuel — UI Reference Pack

Paket ini dibuat sebagai referensi desain untuk AI coding agent.

## Isi
- `index.html` — prototype UI interaktif multi-halaman untuk dilihat di browser.
- `styles.css` — visual theme dan responsive layout.
- `app.js` — navigasi demo dan interaksi ringan.
- `DESIGN_SYSTEM.md` — brand colors, typography, komponen, prinsip UX, peta layar.
- `AI_IMPLEMENTATION_PROMPT.md` — prompt siap diberikan kepada coding agent.
- `assets/mari-partner-logo.png` — logo yang diberikan pemilik.

## Cara melihat
Ekstrak ZIP, lalu buka `index.html` dengan browser modern. Internet diperlukan untuk memuat Google Fonts; tanpa internet akan memakai font fallback.

## Catatan penting
Ini adalah prototype referensi visual, bukan aplikasi Android yang sudah terhubung ke Supabase. Data pada layar merupakan data ilustrasi, bukan data transaksi nyata. Beberapa tombol hanya berpindah halaman atau menampilkan notifikasi demo. Agent wajib mengimplementasikan ulang dengan Kotlin + Jetpack Compose + Material 3 dan menghubungkannya ke business logic yang sudah ada.

## Identitas visual
Mari Partner Fuel menggunakan warna utama navy/biru/cyan sesuai logo. Jangan mengubah logo atau menggunakan warna brand yang tidak konsisten tanpa persetujuan.
